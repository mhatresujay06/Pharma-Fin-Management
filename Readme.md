# Pharma Fin Management

## Project Description

Pharma Fin Management is a software project for managing financial activities in a pharmaceutical organization.

## Objectives

- Manage financial records
- Track expenses and transactions
- Manage financial information
- Generate financial reports

## Project Modules

- Finance Management
- Expense Management
- Transaction Management
- Financial Reports

## Technologies

- Git
- GitHub

## Version Control

Git is used to track changes in the project, while GitHub is used to store and manage the project repository.

## Conclusion

This project demonstrates the use of Git and GitHub for version control and project management.
